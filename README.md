### 🚀 Featured Engineering & Embedded Projects

* **[Pico-Vga-Python](https://github.com/bayeggex/Pico-Vga-Python):** Generating direct VGA display signals (HSYNC, VSYNC, RGB) using a Raspberry Pi Pico (RP2040) and MicroPython. Demonstrates low-level timing control, PIO state machine capabilities, and resistor DAC video generation on a microcontroller.
* **[MicroCraft-ESP32](https://github.com/bayeggex/MicroCraft-ESP32):** An experimental bare-metal Minecraft server implementation running on an ESP32 microcontroller using raw TCP sockets without external networking abstraction libraries. Optimized for low-RAM constraints (520 KB SRAM).
* **[AIChatBot (PlatformIO / Arduino)](https://github.com/bayeggex/Arduino-AI-Chat-Library):** Lightweight embedded client library designed to interface resource-constrained microcontrollers with LLM and generative AI APIs over HTTP/HTTPS.
